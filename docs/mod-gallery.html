What a mod can do behind the drawing

Read and act

Read and write files, list folders, run processes, make HTTP calls, run slash commands and skills.

Think on the side

Call a cheap model without touching the chat, like your rolling handoff draft on Haiku.

Remember

Keep values per chat or across chats. A change redraws whatever reads it.

React

Turn ends, tool calls, prompts, /clear, chat start. Your plan tie runs on file edits.

Limits: no HTML or CSS, layout is flexbox in character cells, borders wrap a whole box, no file watching, and a hotkey works only once its band or pane has focus. Details in UI-TOOLKIT.md.
